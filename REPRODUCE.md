# Reproducing the study

Run every command from the repository root with the dependencies in `requirements.txt`. The data directories
(`testbed_data/`, `dev_data/`) are generated by these commands and are not versioned. The lock-box files in
`lockbox/` hold the hashes that every generated zone and injection file must match.

## 0. Tests
```
python -m pytest -q tests
```

## 1. Testbed (MIMIC-III Waveform Database Matched Subset numerics, ODbL; no credentials needed)
```
python testbed/fetch_numerics.py --patients 400                    # headers, seeded patient draw
python testbed/fetch_numerics.py --patients 400 --data --rate 1.0  # 1 Hz records only
python testbed/assign_zones.py                                     # 120/40/41 patients -> lockbox/testbed_zones.json
python testbed/generator.py --zone A                               # then --zone B, --zone C with --allow-zone
python testbed/check_zone.py A                                     # order, pairing, record reproduced
python testbed/window_zone.py --zone A                             # then B, C with --allow-zone
```
Rules: `protocol/TESTBED_SCORERS.md`. Hashes: `lockbox/testbed_manifest.json`.

## 2. Ward-level study (Zone C)
```
python -c "import yaml,run_dev; run_dev.stage_select(yaml.safe_load(open('configs/protocol.yaml')), 'testbed_data/windows/zone_A.csv', 'results/testbed')"
python testbed/run_testbed.py --stage train
python testbed/run_testbed.py --stage inject
python testbed/run_testbed.py --stage copies
python testbed/run_testbed.py --stage evaluate                     # -> results/testbed/eval_zoneC.json
```

## 3. Bed-level study (Zone D)
```
python testbed/walk_zone_d.py                                      # Zone D list from headers only
python testbed/perbed.py --stage windows --zone A                  # then --zone B --allow-zone
python testbed/perbed.py --stage select
python testbed/perbed.py --stage train
# fetch the Zone D records named in lockbox/testbed_zone_D.json, then:
python testbed/generator.py --zone D --allow-zone
python testbed/perbed.py --stage windows --zone D --allow-zone
python testbed/perbed.py --stage inject
python testbed/perbed.py --stage copies
python testbed/perbed.py --stage evaluate                          # -> results/perbed/eval_zoneD.json
```
Rules: `protocol/PERBED_PROTOCOL.md`.

## 4. Development run (low-background simulated stream)
```
for s in split inject windows select train evaluate; do python run_dev.py --stage $s; done
```
Rules: `protocol/PROTOCOL.md`. This run and the Replay and Flood timing of the testbed attacks read the simulated
stream in `baseline_data/interleaved/` (about 685 MB), which is not included in the repository.

## 5. Tables and figures of the paper
```
python paper/make_tables.py     # paper/tables/*.tex and paper/numbers.tex
python paper/make_figures.py    # paper/figures/*.pdf (the rate figure also reads the generated Zone A events)
```
Every result number in the paper comes from these two scripts.
